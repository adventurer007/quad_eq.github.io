Квадратные уравнения

Виды квадратных уравнений

Квадратное уравнение имеет вид ax^2 + bx + c = 0, где a ≠ 0. Если b или c равно нулю, уравнение неполное.

ax^2 + bx + c = 0
Полное. Решается через дискриминант.
ax^2 + bx = 0
Нет свободного члена. Выносим x за скобки: x(ax + b) = 0. Корни: 0 и −{b|a}.
ax^2 + c = 0
Нет члена с x. Получаем x^2 = −{c|a}. Если справа положительное число, корней два: ±√[−{c|a}]. Если отрицательное, корней нет.
ax^2 = 0
Только x². Единственный корень x = 0.

Произведение равно нулю, когда равен нулю хотя бы один множитель: a·b·c = 0 ⟺ a = 0 или b = 0 или c = 0.

Дискриминант и формула корней

D = b^2 − 4ac, x = {−b ± √[D]|2a}

D > 0

два различных корня

D = 0

один корень x = −{b|2a}

D < 0

действительных корней нет

Лаборатория дискриминанта

Двигайте ползунки: смотрите, как коэффициенты меняют параболу и число корней.

Теорема Виета

ax^2 + bx + c = 0
x_1 + x_2 = −{b|a}, x_1x_2 = {c|a}
x^2 + px + q = 0
x_1 + x_2 = −p, x_1x_2 = q

Полезные выражения для задач блока C:

  • x_1^2 + x_2^2 = (x_1 + x_2)^2 − 2x_1x_2
  • x_1^3 + x_2^3 = (x_1 + x_2)^3 − 3x_1x_2(x_1 + x_2)
  • {1|x_1} + {1|x_2} = {x_1 + x_2|x_1x_2}

Разложение трёхчлена

ax^2 + bx + c = a(x − x_1)(x − x_2)

Здесь x_1, x_2 — корни уравнения. Так сокращают алгебраические дроби: раскладываем числитель и знаменатель на множители и убираем общий.

Разбор типовых задач

Методы решения

Уравнения высших степеней сводят к квадратным с помощью замены переменной. Метод выбирают по виду уравнения.

ax^4 + bx^2 + c = 0
Биквадратное уравнение (a ≠ 0). Замена t = x^2, где t ≥ 0, даёт квадратное уравнение at^2 + bt + c = 0.
ax^<2n> + bx^<n> + c = 0
Приводится к квадратному подстановкой t = x^<n>.
a(g(x))^2 + bg(x) + c = 0
Замена сложного выражения. Обозначаем t = g(x).
ax^4 + bx^3 + cx^2 + bx + a = 0
Симметричное (возвратное) уравнение. Делим на x^2 ≠ 0 и вводим t = x + {1|x}.
x^3 − 3x^2 − 4x + 12 = 0
Группировка и разложение. Группируем слагаемые: x^2(x − 3) − 4(x − 3) = (x − 3)(x^2 − 4). Если группировки нет, подбираем целый корень среди делителей свободного члена.

Проверка после замены. Если t = x^2 и получилось t < 0, действительных корней у такого уравнения нет, это значение t отбрасываем.

Разбор типовых задач

Основные понятия

Уравнение вида {f(x)|g(x)} = 0 называется дробно-рациональным. Область допустимых значений (ОДЗ) состоит из всех x, при которых знаменатель не равен нулю: g(x) ≠ 0.

Дробь равна нулю тогда и только тогда, когда её числитель равен нулю, а знаменатель определён и не равен нулю:

{f(x)|g(x)} = 0 ⟺f(x) = 0g(x) ≠ 0

Алгоритм решения

  1. Найти ОДЗ: исключить значения x, при которых знаменатели равны 0.
  2. Найти наименьший общий знаменатель дробей.
  3. Умножить обе части уравнения на общий знаменатель (или перенести всё в одну сторону и привести к общей дроби).
  4. Решить полученное целое рациональное уравнение.
  5. Исключить посторонние корни, не входящие в ОДЗ.

Замена переменной. Если в уравнении повторяется одна и та же дробь или трёхчлен, обозначьте его через t (пример 2).

Разбор типовых задач

Определение и ОДЗ

  • Уравнение, содержащее переменную под знаком корня (радикала), называется иррациональным.
  • ОДЗ квадратного корня. Подкоренное выражение под корнем чётной степени должно быть неотрицательным: f(x) ≥ 0.
  • Корень нечётной степени, например ∛[f(x)], определён при любых значениях f(x).

Равносильные схемы

√[f(x)] = √[g(x)] ⟺f(x) = g(x)f(x) ≥ 0 (или g(x) ≥ 0)

√[f(x)] = g(x) ⟺g(x) ≥ 0f(x) = (g(x))^2

Замена переменной. При повторяющемся выражении вводим √[f(x)] = t, где t ≥ 0.

Проверка. Возведение в квадрат может добавить посторонние корни. Если нет равносильной системы, найденные значения нужно проверить подстановкой.

Разбор типовых задач

Модуль и основные схемы

Модуль числа |a| — расстояние от начала отсчёта до точки a, поэтому он не бывает отрицательным.

|a| = a при a ≥ 0
и |a| = −a при a < 0. Всегда |a|^2 = a^2.
|f(x)| = a, a ≥ 0
Равносильно f(x) = a или f(x) = −a. При a < 0 корней нет.
|f(x)| = g(x)
Равносильно системе: g(x) ≥ 0 и (f(x) = g(x) или f(x) = −g(x)).
|f(x)| = |g(x)|
Равносильно f(x) = g(x) или f(x) = −g(x).

Метод интервалов для модулей. Отметьте на прямой точки, где подмодульные выражения обращаются в ноль, раскройте модули по знаку на каждом промежутке и проверьте корни на своём промежутке.

Лаборатория: |2x − 1| = x + c

Двигайте ползунок c. Смотрите, сколько точек пересечения даёт прямая y = x + c с графиком модуля.

Разбор типовых задач

Методы решения систем

Систему двух уравнений с двумя переменными решают так, чтобы свести её к одному уравнению с одной переменной. Для этого есть два основных приёма.

⟨ax + by = c ‖ dx + ey = f⟩
Сложение. Умножьте одно уравнение на число, чтобы при сложении или вычитании исчезла одна переменная.
y = x − 4
Подстановка. Выразите одну переменную из простого уравнения и подставьте её в другое.
x + y = s, xy = p
Симметричные системы. Не меняются при замене x на y. Вводят s и p и решают по теореме Виета.

Проверка. Каждую найденную пару подставьте в оба уравнения системы. Если в системе есть дроби, проверьте, что знаменатели не обращаются в ноль.

Лаборатория: пересечение прямых

Меняйте коэффициенты двух прямых. Точка их пересечения — решение системы.

Разбор типовых задач

Линейные неравенства

Линейное неравенство решают так же, как линейное уравнение, но с одним правилом: при умножении или делении на отрицательное число знак неравенства меняется.

kx + c > 0, kx + c < 0
Строгие неравенства: точка не входит в ответ.
kx + c ≥ 0, kx + c ≤ 0
Нестрогие неравенства: точка входит в ответ.
(a; b), [a; b), [a; b]
Запись ответа. Круглая скобка — конец не входит, квадратная — входит. +∞ и −∞ всегда в круглых скобках.

Лаборатория: линейное неравенство

Меняйте k, c и знак. Жирный отрезок на оси — множество решений, закрашенная точка входит в ответ, выколотая — нет.

Разбор типовых задач

Квадратные неравенства и метод интервалов

Квадратный трёхчлен ax^2 + bx + c раскладывают на множители и отмечают его корни на числовой прямой. Затем определяют знаки на интервалах.

f(x) ≤ 0
Алгоритм метода интервалов. Приведите неравенство к виду f(x) ≥ 0 или f(x) < 0, найдите нули, отметьте их на прямой и определите знаки на интервалах.
(x − a)^2
Чётная кратность. При переходе через корень знак функции не меняется. Корень всё равно входит в ответ, если неравенство нестрогое.
(x − a)^3
Нечётная кратность. При переходе через корень знак меняется.
D < 0
Если дискриминант отрицателен, трёхчлен сохраняет знак старшего коэффициента a при всех x.

Лаборатория: квадратное неравенство

Меняйте a, b, c и знак. Жирный отрезок на оси — множество решений. Ветви вверх при a > 0, вниз при a < 0.

Разбор типовых задач

Дробно-рациональные неравенства

Неравенство вида {P(x)|Q(x)} ≥ 0 (или с другим знаком) решают методом интервалов, но с важной оговоркой: знаменатель не может быть равен нулю.

{P(x)|Q(x)} ≥ 0
Перенос в одну сторону. Все слагаемые переносят в левую часть и приводят к общему знаменателю. Справа остаётся ноль.
Q(x) = 0
Корни знаменателя всегда выколоты, даже если неравенство нестрогое.
P(x) = 0
Корни числителя закрашены для ≥ и ≤, выколоты для > и <.

Не умножайте обе части на выражение с x. Знак такого выражения неизвестен, поэтому сначала переносите всё в одну сторону и приводите к дроби.

Лаборатория: дробно-рациональное неравенство

Меняйте p и q. Нуль знаменателя q всегда выколот, нуль числителя p зависит от знака неравенства.

Разбор типовых задач

Системы неравенств

Система неравенств — это несколько неравенств с одной переменной, которые должны выполняться одновременно. Решение системы — общая часть решений всех её неравенств.

A ∩ B
Система. Общая часть решений: решите каждое неравенство и найдите пересечение промежутков.
A ∪ B
Совокупность. Объединение решений: встречается, когда в задаче стоит «или».

Алгоритм. Решите каждое неравенство отдельно, отметьте решения на одной числовой прямой и выберите общий промежуток.

Лаборатория: две линейные неравенства

У каждого неравенства своя ось. Перетаскивайте точку на оси: подсвечена часть оси, где неравенство выполняется. Зелёная область соединяет оси там, где их решения пересекаются.

Разбор типовых задач

Иррациональные неравенства

Квадратный корень существует только при неотрицательном подкоренном выражении, поэтому ОДЗ нужно учитывать всегда. Корень нечётной степени определён при любых значениях подкоренного выражения.

√[f] < g
Равносильно системе: f ≥ 0, g > 0 и f < g^2.
√[f] > g
Совокупность: g < 0, f ≥ 0 или g ≥ 0, f > g^2.
√[f] < √[g]
Равносильно: f ≥ 0 и f < g.
∛[f] < g
Равносильно f < g^3. Ограничений на f нет.

Не возводите в квадрат без анализа знака. Левая часть корня неотрицательна, поэтому возведение в квадрат имеет смысл только для неотрицательной правой части.

Лаборатория: корень и прямая

График √(px + q) и прямая y = kx + m. Там, где дуга лежит ниже прямой, находятся решения неравенства √f < g.

Разбор типовых задач

Неравенства с модулем

Модуль числа — расстояние от нуля, поэтому неравенства с модулем раскрывают через совокупности и системы без вычисления самого модуля.

|f| < a (a > 0)
Равносильно −a < f < a.
|f| > a (a > 0)
Совокупность: f > a или f < −a.
|f| < g
Система: f < g и f > −g.
|f| < |g|
Равносильно f^2 < g^2.

Метод интервалов. Найдите нули всех подмодульных выражений, разбейте прямую на промежутки и раскройте модули по знакам на каждом из них.

Лаборатория: |x − a| + |x + b| ≤ c

Сумма расстояний до двух точек. Двигайте ползунки и смотрите, где график лежит ниже прямой y = c.

Разбор типовых задач

Арифметическая прогрессия

Последовательность, в которой каждый следующий член получается прибавлением одного и того же числа d.

a_ = a_1 + (n − 1)d
Формула n-го члена. Связь любых двух членов: a_ = a_ + (n − k)d.
a_ = {a_ + a_|2}
Характеристическое свойство: каждый член — среднее соседних.
S_ = {a_1 + a_|2} · n
Сумма n членов. Удобно, если известен последний член.
S_ = {2a_1 + (n − 1)d|2} · n
Сумма через первый член и разность.

Равноотстоящие члены. Если n + k = m + p, то a_ + a_ = a_ + a_

. Поэтому пары членов с одинаковой суммой номеров дают одинаковую сумму.

Лаборатория 1: прямоугольник из пар

Синие столбики — члены прогрессии, жёлтые — те же члены в обратном порядке, поставленные сверху. Каждый столбик в сумме даёт a_1 + a_n, поэтому весь набор — прямоугольник, и сумма — его половина.

Лаборатория 2: шаг прогрессии

Члены — точки на прямой. Выберите a_1, d и номер k: видно, как каждый шаг добавляет d, и как по a_1 получить a_k.

Разбор типовых задач

Геометрическая прогрессия

Последовательность, в которой каждый следующий член получается умножением на одно и то же число q, при b_1 ≠ 0, q ≠ 0.

b_ = b_1 q^
Формула n-го члена. Связь: b_ = b_ q^.
b_^2 = b_ · b_
Характеристическое свойство: квадрат члена равен произведению соседних.
S_ = {b_1(q^ − 1)|q − 1}
Сумма n членов при q ≠ 1.
S = {b_1|1 − q}
Сумма бесконечно убывающей прогрессии, |q| < 1.

Сходимость. Бесконечная сумма имеет конечное значение только при |q| < 1. При |q| ≥ 1 частичные суммы не стремятся к пределу.

Лаборатория 1: квадраты из сторон прогрессии

Стороны квадратов — члены прогрессии b_1, b_1q, b_1q², … Ряд квадратов выстраивается в линию. При |q| < 1 его длина стремится к пределу, он отмечен красной линией.

Лаборатория 2: мяч, который отскакивает

Каждый отскок в q раз ниже предыдущего. Путь мяча — сумма падений и подъёмов, и при |q| < 1 он конечен.
