Квадратные уравнения

Виды квадратных уравнений

Квадратное уравнение имеет вид ax^2 + bx + c = 0, где a ≠ 0. Если b или c равно нулю, уравнение неполное.

ax^2 + bx + c = 0
Полное. Решается через дискриминант.
ax^2 + bx = 0
Нет свободного члена. Выносим x за скобки: x(ax + b) = 0. Корни: 0 и −{b|a}.
ax^2 + c = 0
Нет члена с x. Получаем x^2 = −{c|a}. Если справа положительное число, корней два: ±√[−{c|a}]. Если отрицательное, корней нет.
ax^2 = 0
Только x². Единственный корень x = 0.

Произведение равно нулю, когда равен нулю хотя бы один множитель: a·b·c = 0 ⟺ a = 0 или b = 0 или c = 0.

Дискриминант и формула корней

D = b^2 − 4ac, x = {−b ± √[D]|2a}

D > 0

два различных корня

D = 0

один корень x = −{b|2a}

D < 0

действительных корней нет

Лаборатория дискриминанта

Двигайте ползунки: смотрите, как коэффициенты меняют параболу и число корней.

Теорема Виета

ax^2 + bx + c = 0
x_1 + x_2 = −{b|a}, x_1x_2 = {c|a}
x^2 + px + q = 0
x_1 + x_2 = −p, x_1x_2 = q

Полезные выражения для задач блока C:

  • x_1^2 + x_2^2 = (x_1 + x_2)^2 − 2x_1x_2
  • x_1^3 + x_2^3 = (x_1 + x_2)^3 − 3x_1x_2(x_1 + x_2)
  • {1|x_1} + {1|x_2} = {x_1 + x_2|x_1x_2}

Разложение трёхчлена

ax^2 + bx + c = a(x − x_1)(x − x_2)

Здесь x_1, x_2 — корни уравнения. Так сокращают алгебраические дроби: раскладываем числитель и знаменатель на множители и убираем общий.

Разбор типовых задач

Методы решения

Уравнения высших степеней сводят к квадратным с помощью замены переменной. Метод выбирают по виду уравнения.

ax^4 + bx^2 + c = 0
Биквадратное уравнение (a ≠ 0). Замена t = x^2, где t ≥ 0, даёт квадратное уравнение at^2 + bt + c = 0.
ax^<2n> + bx^<n> + c = 0
Приводится к квадратному подстановкой t = x^<n>.
a(g(x))^2 + bg(x) + c = 0
Замена сложного выражения. Обозначаем t = g(x).
ax^4 + bx^3 + cx^2 + bx + a = 0
Симметричное (возвратное) уравнение. Делим на x^2 ≠ 0 и вводим t = x + {1|x}.
x^3 − 3x^2 − 4x + 12 = 0
Группировка и разложение. Группируем слагаемые: x^2(x − 3) − 4(x − 3) = (x − 3)(x^2 − 4). Если группировки нет, подбираем целый корень среди делителей свободного члена.

Проверка после замены. Если t = x^2 и получилось t < 0, действительных корней у такого уравнения нет, это значение t отбрасываем.

Разбор типовых задач

Основные понятия

Уравнение вида {f(x)|g(x)} = 0 называется дробно-рациональным. Область допустимых значений (ОДЗ) состоит из всех x, при которых знаменатель не равен нулю: g(x) ≠ 0.

Дробь равна нулю тогда и только тогда, когда её числитель равен нулю, а знаменатель определён и не равен нулю:

{f(x)|g(x)} = 0 ⟺f(x) = 0g(x) ≠ 0

Алгоритм решения

  1. Найти ОДЗ: исключить значения x, при которых знаменатели равны 0.
  2. Найти наименьший общий знаменатель дробей.
  3. Умножить обе части уравнения на общий знаменатель (или перенести всё в одну сторону и привести к общей дроби).
  4. Решить полученное целое рациональное уравнение.
  5. Исключить посторонние корни, не входящие в ОДЗ.

Замена переменной. Если в уравнении повторяется одна и та же дробь или трёхчлен, обозначьте его через t (пример 2).

Разбор типовых задач

Определение и ОДЗ

  • Уравнение, содержащее переменную под знаком корня (радикала), называется иррациональным.
  • ОДЗ квадратного корня. Подкоренное выражение под корнем чётной степени должно быть неотрицательным: f(x) ≥ 0.
  • Корень нечётной степени, например ∛[f(x)], определён при любых значениях f(x).

Равносильные схемы

√[f(x)] = √[g(x)] ⟺f(x) = g(x)f(x) ≥ 0 (или g(x) ≥ 0)

√[f(x)] = g(x) ⟺g(x) ≥ 0f(x) = (g(x))^2

Замена переменной. При повторяющемся выражении вводим √[f(x)] = t, где t ≥ 0.

Проверка. Возведение в квадрат может добавить посторонние корни. Если нет равносильной системы, найденные значения нужно проверить подстановкой.
